# CONTRIBUTING

## Guidelines

### Bugs

-   Ensure that hasn't already been reported under [issues](https://github.com/Vali-98/ChatterUI/issues).
-   Be sure to add information on how to reproduce the bug:
    -   Device type
    -   App version
    -   Model or API (if relevant)
    -   Attach ChatterUI logs `Side Menu` > `Logs` > `Export`
    -   Add relevant screenshots
    -   Describe a step-by-step reproduction of the issue

### Pull Requests

0. Before submitting a PR, raise it as an issue unless the fix is minor (one line fixes, spelling corrections, etc).
1. Avoid unit/component tests, as ChatterUI uses few at the moment.
2. Run `lint` and `prettier` to format code before submitting.
3. Ensure `i18n` translations are properly implemented if needed.
4. If a PR introduces a new dependency or modifies the `package.json`, it will likely be under higher scrutiny and lower acceptance rate.

### Notes on AI use

AI usage is not strictly prohibited, however it is expected that PR descriptions are human-made and well reasoned. Ensure that the codebase is clear of any AI specific tooling artifacts (promps, AGENT.md, etc) and config changes.

AI generated changes of more than 50 lines will likely be rejected outright.

## Development

### Android

To run a development build, follow these simple steps:

-   Install any Java 17/21 SDK of your choosing
-   Install `android-sdk` via `Android Studio`
-   Clone the repo:

```
git clone https://github.com/Vali-98/ChatterUI.git
```

-   Install dependencies via npm and run via Expo:

```
npm install
npx expo run:android
```

#### Building an APK

Requires Node.js, Java 17/21 SDK and Android SDK. Expo uses EAS to build apps which requires a Linux environment.

1. Clone the repo.
2. Rename the `eas.json.example` to `eas.json`.
3. Modify `"ANDROID_SDK_ROOT"` to the directory of your Android SDK
4. Run the following:

```
npm install
eas build --platform android --local
```
